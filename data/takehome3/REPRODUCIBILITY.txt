TAKE-HOME EXERCISE 3
Completed analytical workflow, 14 November 2026

Open ISSS626geo.Rproj and use the project root as the working directory.

The Quarto technical report is take-home_ex03.qmd.
The Quarto revealjs executive summary is take-home_ex03_slides.qmd.
The latter contains ten content slides, one cover and one contents slide.

R packages: sf, data.table, units, ggplot2, patchwork, scales, leaflet,
htmltools, knitr, rmarkdown, DT, spdep, ggrepel and MCI (unit tests).
Versions used in the analysis are recorded in results/R-session-info.txt.

In the RStudio Terminal, render these files individually:
quarto render take-home_ex03.qmd --to html
quarto render take-home_ex03_slides.qmd --to revealjs
quarto render index.qmd --to html

The technical report executes the source preparation, Poisson calibration,
scenario allocation, accessibility comparison and residual diagnostics.
The slides read the matching final results. If the results cache is missing
or the analysis scripts or manifests change, the slide setup rebuilds it.
The cached glm objects omit dense fitting matrices and are intended for
reporting, not for refitting. The original R scripts rebuild complete fits.

Run Rscript scripts/test_takehome3_extensions.R for the final scenario,
accessibility and slide structure checks. The earlier test_takehome3.R
checks the first stage and needs the stage1_results.rds generated by
Rscript scripts/takehome3_analysis.R.

Raw data sources and checksums:
- public_download_manifest.csv
- ridership_manifest.csv
The station coordinate dataset licence is in raw/stations/LICENSE-DATASET.md.
The large HDB GeoJSON and three OD CSVs are stored as lossless .gz snapshots.
scripts/takehome3_io.R restores absent originals and checks their checksums.
Rendering does not need an API key or a live download. Results RDS files are
rebuildable and ignored by Git. Keep the source snapshots and manifests.

The main findings use conditional destination arrivals from existing origin
stations. They are not a forecast of unknown future total rail demand.
Future results use the same October 2026 weekday origin totals for both
choice sets. Existing station impacts compare future and baseline MODEL
estimates. No observed future outcomes are fabricated.

Bonus analysis addresses a separate spatial question: where do HDB building
records gain geographic access, and does that ranking agree with the
ridership allocation? Distance thresholds, model sensitivity and spatial
residual checks qualify the interpretation. Building counts are not
household or population counts. Straight line access is not walking time.

The independent Hands-on 10 page still requires its missing Chapter 14
mdata.rds. A full website render can stop there. That dependency is not
required by the Take-home 3 report or slides.
